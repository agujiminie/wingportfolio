# Cat gaze frames（猫咪跟随 cursor 的照片素材）

`#/cat` 页面（`src/CatPage.jsx` → `src/components/cat/CatGaze.jsx`）用的是
**同一只猫、25 张不同注视方向的静态照片**，按 cursor 相对猫脸的方向硬切。
这个文件夹里放照片；没有照片时页面自动用程序画的占位猫（`catFrames.js`
里的 `PLACEHOLDER_FRAMES`），照片一放进来即自动切换成真图（无需改代码）。

## 命名规则（必须一致）

```
r{row}-c{col}.webp      row、col 都是 0–4
```

| | c0 | c1 | c2 | c3 | c4 |
|---|---|---|---|---|---|
| **r0**（往上看） | 上·左 | 上·微左 | 正上 | 上·微右 | 上·右 |
| **r1** | 微上·左 | 微上·微左 | 微上 | 微上·微右 | 微上·右 |
| **r2** | 左 | 微左 | **直视镜头** | 微右 | 右 |
| **r3** | 微下·左 | 微下·微左 | 微下 | 微下·微右 | 微下·右 |
| **r4**（往下看） | 下·左 | 下·微左 | 正下 | 下·微右 | 下·右 |

- **左 / 右 = 观众看到的方向**（照片里猫脸朝画面左边 = c0）。
- 支持 `.webp` `.jpg` `.jpeg` `.png`；某格没拍到会自动借用最近的一格，不会报错。
- 换猫脸位置：`CatGaze` 的 `faceAnchor` prop（默认 `{ x: 0.5, y: 0.42 }`，
  即脸在画面横向正中、纵向 42% 处）。

## 拍摄指南（保证硬切时"只有头在动"）

1. **相机固定**：手机/相机上三脚架，25 张全程不动；锁定曝光和对焦（iPhone 长按取景框 AE/AF LOCK）。
2. **猫固定**：猫坐在同一个位置（垫子/纸箱上），身体尽量不动，只让头和眼睛动。
3. **背景干净**：白墙或纯色布，光线均匀（窗边侧光 + 白色反光板 / 或室内主灯即可），避免阴影乱跑。
4. **引导视线**：想象镜头周围有一个 5×5 的格子——横向约 ±15°（c1/c3）和 ±30°（c0/c4），
   纵向约 ±10°（r1/r3）和 ±20°（r0/r4）。用逗猫棒 / 激光笔 / 零食把猫的视线逐格引过去，
   每格连拍几张挑最清楚的。`r2-c2` 是直视镜头（可用零食贴在镜头旁）。
5. **构图**：猫头在画面上部 ~40% 高度的位置，胸口进画面、四周留白（参考视频的取景：
   头部占画面宽度约 60%）。竖构图或 4:5 均可，25 张比例保持一致。
6. **交付**：原图（不要先裁）打包发我，我统一裁切对齐（以眼睛/鼻子为基准）、
   缩到长边 1400px、转 WebP q80（每张约 100–150KB，全部 ≈ 3MB），再放进这个文件夹。
